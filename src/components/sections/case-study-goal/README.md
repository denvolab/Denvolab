# case-study-goal

The AI Assistant page's "// Project Goal" block, in Inter: a label, a statement with lighter and darker runs, a hairline, the project facts on a tick "ruler" (Project, Industry, Time, Location) and four outlined chips.

From `xl` the facts sit at the same spots along the ruler as in Figma (positions are percentages of the 1007px row). Below `xl` they become a two-column list and the ruler is dropped.
