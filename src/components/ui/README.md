# `ui/` — Generic, Reusable Pieces

Small building blocks with no page-specific meaning. Nothing in here should know or care what page it's used on.

| Folder | Contains |
|---|---|
| [`button/`](./button/) | The one `Button` used everywhere — nav links, footer links, CTAs — with two visual styles ("primary" solid lime, "ghost" text link). |

More will land here as the site grows (inputs, cards, badges, etc.) — each gets its own folder the same way `button/` does.
