# `seo/` — Search-Engine-Only Components

Components in here render **nothing visible**. Their only job is to give search engines extra machine-readable information about the site.

| Folder | Contains |
|---|---|
| [`organization-jsonld/`](./organization-jsonld/) | A hidden `<script>` tag describing Denvo Lab as a business (name, URL, socials) in the schema.org format Google reads. |
