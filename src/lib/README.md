# `lib/` — Logic & Data (no visual components here)

If `components/` is "what the page looks like," `lib/` is "where the words and numbers come from, and the small helper functions everything relies on."

| Folder | What it holds |
|---|---|
| [`data/`](./data/README.md) | The actual nav/footer content, and the functions that fetch it — the most important folder to understand for the future admin panel. |
| [`seo/`](./seo/README.md) | Site-wide facts (name, URL, socials) used for metadata and structured data. |
| [`utils/`](./utils/README.md) | Small generic helper functions used across the codebase. |
