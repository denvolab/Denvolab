# `utils/`

| File | Holds |
|---|---|
| `cn.ts` | The `cn()` helper used to combine Tailwind classes safely (e.g. conditional classes without duplicate/conflicting utilities). Used throughout `components/`. |
| `fluid.ts` | Helpers for layouts copied from the 1920 Figma frame: `fluid(96)` is a length that is 96px at full width and shrinks with the screen, `pctOf(470)` is 470px as a share of 1920. Used by the case study sections. |
